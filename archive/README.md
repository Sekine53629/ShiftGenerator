## Sidebar.gs / Sidebar.html

- **置いた日**: 2026-09-03
- **理由**: シフト表ごと Web アプリ化する方針に変わり、サイドバーは役目を失った

仕様書 `docs/GAS-PORTING-SPEC.md` §6 は「クリック入力パレットはサイドバー（HtmlService）で
代替する」を確定方針にしていて、この2ファイルはその骨組みでした。
2026-09-03 に利用者の判断で Web アプリ化が決まり、入力の経路は
`WebApp.gs` / `WebAppView.html` に一本化されました（`docs/WEBAPP-DESIGN.md`）。

中身は骨組み（`notImplemented_` を投げるだけ）のままで、実装には入っていません。

### 貼り付けてはいけない理由が2つあります

1. **ファイル名が衝突する。**
   Apps Script はファイル名が拡張子をまたいで一意でなければならず、
   `Sidebar.gs` と `Sidebar.html` は同じ「Sidebar」として扱われて共存できません
   （この制約を踏んだのが、そもそもこのファイルを片付けた直接のきっかけでした）。
2. **関数名がグローバルスコープでぶつかる。**
   `.gs` は全ファイルが1つのグローバルスコープを共有します。
   `Sidebar.gs` の `classifyTargetArea_` などは、`WebApp.gs` の同種の関数と
   役割が重なっています。

### 中身を再利用したくなったら

サイドバーを復活させるのではなく、**仕様として使える部分だけ拾う**のが筋です。
実際、次の3つは Web アプリ側へ移してあります。

| 旧サイドバーの要件 | 移った先 |
|---|---|
| §6.3 押せる場所の制約（`StampAllowedHere`） | `WebApp.stampRejectReason_()` |
| §6.4 医師名スタンプ（実名をコードに書かない） | `ShiftAuto.readDoctorNames()` |
| §6.5 値と太字だけ書く／数式セルは触らない | `WebApp.apiSaveCells()` |

まだ移していないのは **§6.7 の月送り**（`AG{headerRow}` を動かして期替わりを問う）と
**背景色の塗り分け**です。必要になったらここの記述を参考にしてください。
