# シフト作成ツール {{VERSION}}

薬局のスタッフのシフト表を作るツールです。医師の出勤人数から必要な薬剤師の人数を出し、
希望休を守りながら、早番・遅番・遅半をスタッフのあいだで均等に配ります。

**`ShiftGenerator.html` 1つで動きます。** インストールもインターネットも要りません。
データはこのパソコンの中（選んだフォルダ）にだけ保存されます。

---

## 入っているもの

| ファイル | |
|---|---|
| `ShiftGenerator.html` | ツール本体。Microsoft Edge か Google Chrome で開く |
| `install-local.ps1` | ドキュメントにフォルダを作り、HTML とデスクトップのショートカットを置く（任意） |
| `README.md` | この説明 |

## 置き方

**かんたんな方法:** `install-local.ps1` を右クリック →「PowerShell で実行」。
`ドキュメント\ShiftGenerator` に HTML が置かれ、デスクトップに「シフト作成」ができます（Edge で開きます）。

実行できないときは、PowerShell で次のように実行してください。

```
powershell -ExecutionPolicy Bypass -File .\install-local.ps1
```

**手で置く場合:** 好きなフォルダに `ShiftGenerator.html` を置き、Edge か Chrome で開きます。

新しい版にするときも同じ手順です。**保存したデータ（`data` フォルダ）には触りません。**

## はじめて開いたとき

1. 画面の **「保存先フォルダを選ぶ（初回だけ）」** で、HTML を置いたフォルダ（`ShiftGenerator`）を選ぶ
2. **社員マスタ**に人を入れる（薬剤師・派遣・事務の表に分かれています。⠿ をドラッグで並べ替え）
3. **医師マスタ**に医師を入れる
4. 年月を選び、医師名の欄を埋める（医師の人数が分かれば足ります）
5. 希望休・有休を入れてから **「自動生成」** を押す

手で入れたセル（希望休・有休・手で置いたシフト）は緑の文字で出て、自動生成で書き換わりません。
表の下に「確認が要るところ」（週の勤務日数・連勤・早番の人数・遅番の人数など）が出ます。

月ができあがったら **「月を確定」** を押します。次に開いたときは翌月から始まります（前の月も直せます）。

## 出す

| | |
|---|---|
| **PDF** | 印刷画面が開きます。保存先に「PDF に保存」を選んでください。A4 横 1 枚に収まります |
| **スプレッドシート** | `.xlsx` で保存します。集計（公休・早番の回数・過不足など）は数式で入るので、Excel で記号を直すと集計も変わります |

PDF と Excel の色（土曜・日曜・祝日・派遣・事務の行など）は **「出力の色」タブ** で変えられます。

## データはどこにあるか

選んだフォルダの `data` の中です。

| | |
|---|---|
| `data\db.json` | マスタ（社員・医師・設定） |
| `data\cells\2026-11.json` など | シフト（月ごと） |

**このフォルダごと控えを取っておけば、別のパソコンにも移せます。**
「データ書き出し」タブからも、まとめて書き出せます。

## 困ったとき

| | |
|---|---|
| 前に入れたデータが空に見える | いつもと別のブラウザで開いていませんか。データはブラウザごとに別です |
| 保存先フォルダを選べない | Edge か Chrome で開いてください（ほかのブラウザでは使えません） |
| 入力が消えた | 「データ書き出し」の控えを貼って「取り込む」 |
| 印刷が小さい・2 枚になる | 医師名欄の行数を減らすか、在籍期間で人を外してください |

---

氏名はすべて架空の見本です。実際の運用では、各店舗のマスタに入れたものが使われます。
